# Hook playbook (first 3 seconds)

The viewer decides in about 2 seconds. The hook must be a complete, concrete, surprising statement in <= 14 words. It must be true and paid off in the video.

## Patterns (tag each script with `hook_pattern`)
| id | Pattern | Example |
|---|---|---|
| impossible_claim | Something that should not be possible | "In 1925, a con man sold the Eiffel Tower. Then he sold it again." |
| number_shock | A specific number that reframes everything | "One man's typo cost a company four hundred million dollars." |
| mid_action | Start in the middle of the event | "The mayor's phone rang at 3 a.m. The caller was already inside the vault." |
| contradiction | Two facts that clash | "The safest town in America had no police for six years." |
| stakes_first | State the loss, then rewind | "She lost her house over a joke she posted in 2012." |
| forbidden_place | Place that should not exist or be reachable | "There is a town in Norway where dying is illegal." (verify facts before use) |

Only the Lustig example is a verified real story. The others are illustrative shapes; never use them as facts.

## Rules
- First sentence stands alone; the second sentence raises the question the first created.
- Include a number, a name, a place or a date.
- No "Did you know", "Have you ever wondered", "Imagine", "Picture this", "In this video".
- Do not reveal the twist in the hook; reveal the strangeness.
- Generate 8 hook candidates, score them with the rubric, keep the best one. Never ship the first idea.
