# Quality rubric (used by the critique call; 0-10 each)

| Criterion | 10 looks like | Fail if |
|---|---|---|
| Hook | Concrete, surprising, <= 14 words, makes you need sentence 2 | Generic, announcement, question cliche |
| Specificity | A name, place, date or number every 1-2 sentences | Vague nouns, "a man", "a company" without a name when known |
| Escalation | Each beat raises stakes or surprise | Flat list of facts, middle sags |
| Turn | Real twist or consequence in last quarter | Ending is a summary or moral |
| Spoken rhythm | Reads naturally aloud, varied length | Long sentences, written-style prose |
| Loop | Last line echoes hook wording | Ends with CTA or fades out |
| Accuracy | All key claims verifiable, no invented quotes | Any unverifiable claim stated as fact |
| Niche fit | Allowed niche, advertiser-friendly | Science/biology, graphic, risky |

Pass: average >= 7.5 with no criterion below 6 and Accuracy >= 8. The critique call must return the scores plus a concrete rewrite instruction for the two weakest criteria. Deterministic validator errors override the LLM score.
