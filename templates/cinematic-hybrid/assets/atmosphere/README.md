# Atmospheric Environment Kit (`V1`)

Modular procedural atmosphere generators for CurioLoop 2.0.

### Included Systems
1. `volumetric_fog.glsl`: Raymarched 3D fractional Brownian motion fog with light-scattering support.
2. `particle_atmosphere.js`: Pure JavaScript Canvas particle simulator for dust motes, rain streaks, snow, and smoke.
3. `atmosphere_presets.json`: Calibrated lighting and fog density presets for Mystery, History, and Extraterrestrial scenes.

### Execution
- 100% offline; runs on standard HTML5 Canvas 2D or WebGL 1.0/2.0 context.
