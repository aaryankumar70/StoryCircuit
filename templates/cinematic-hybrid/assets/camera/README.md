# Camera and Cinematography Kit (`V2`)

Defines camera trajectory math, quintic easing, perlin drift, and depth-of-field simulation for CurioLoop 2.0.

- `camera_rig.js`: Smooth trajectory evaluator preventing mechanical jerk.
- `camera_presets.json`: Pre-configured moves (Slow Suspense Push, Macro Rack Focus, Lateral Dolly).
