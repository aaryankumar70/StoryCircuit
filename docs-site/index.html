YouTube Creator Publishing Tool

Original short-form explainers, rendered locally and scheduled cleanly to YouTube.

CurioLoop is a local-first video creation and publishing desktop workflow designed to produce original vertical informational videos (20–30 seconds, 1080×1920) and upload or schedule them directly to the creator's own YouTube channel using Google OAuth 2.0.

Read Privacy Policy Contact Support

What CurioLoop Does

Everything from script authoring to audio synthesis, visual rendering, and quality validation runs locally on the creator's workstation before any video is uploaded to YouTube.

1

Educational Script & Narration

Generates concise curiosity-driven scripts backed by verifiable reference URLs, synthesizes voiceover narration locally, and builds synchronized word-level captions.

2

Local Rendering & Quality Gate

Renders 9:16 H.264/AAC MP4 Shorts locally and checks duration, resolution, loudness (LUFS), peak headroom, and visual timelines before allowing publication.

3

Direct Upload & Scheduling

Uploads verified MP4 files directly to the creator's YouTube channel via the YouTube Data API v3, staging videos as private or scheduling future publication windows (status.publishAt).

YouTube Account Connection via Google OAuth

Creators connect only their own YouTube account using Google's official OAuth 2.0 consent screen.

Explicit Creator Authorization

  • Authentication uses an Installed Desktop OAuth 2.0 client owned by the creator/operator.
  • Requested permissions are limited to uploading videos, reading channel upload status/schedules, and managing scheduled publish timestamps.
  • Creators can review, modify descriptions, pause automation, or revoke access at any time via Google Account permissions.

Privacy-First Local Architecture

  • OAuth refresh tokens and video production records remain stored locally on the operator's computer—CurioLoop operates no central multi-user server.
  • Unrelated Google services (such as Gmail, Drive, or Contacts) are never requested or accessed.
  • Use of Google API data strictly follows Google's API Services User Data Policy and Limited Use requirements.
